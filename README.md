 获取源码：ym7k.com/19203/求职招聘小程序劳务派遣系统灵活用工APP源码搭建-ym7k

 
求职端功能全解析——找工作、找零工、找兼职与简历管理
求职端首页围绕“找工作”核心需求设计，包含八大功能入口：找工作展示全职岗位，找零工展示零工岗位，找兼职展示兼职岗位，提技能跳转小程序客服，政策直达发布政策文本内容，添加意向设置求职类别、职位类别、期望城市和期望月薪，急招展示标记为急招的岗位，推荐展示系统推荐的工作岗位。求职者可根据求职类别和期望城市获得个性化岗位推荐。

职位详情页展示职位名称、薪资、薪资形式、结算方式、企业信息、代招职位和联系人信息。职位描述包含招聘人数、年龄要求、性别要求、学历要求、经验要求、到岗时间和工作地址。职位详情展示职位名称、工作要求、岗位职责、薪资待遇和公司地址。职位待遇展示企业提供的福利待遇。相关推荐展示该公司相关的其他岗位。

职位互动功能包括：职位分享可生成海报并通过微信分享获得积分，每个岗位分享次数和每次分享获取的积分可后台设置；收藏可保存岗位至我的收藏；在线沟通可直接与企业客服聊天；发送简历可将简历投递至该工作岗位。

求职端投递模块与企业端对应，包含消息盒、已投递、被查看、邀面试和不合适五个子页面。消息盒展示职位审核信息、被查看、邀面试、不合适等系统消息；已投递展示求职者投递的简历；被查看展示被企业查看过的简历；邀面试展示收到面试邀请的简历支持在线沟通直接与企业聊天；不合适展示被企业标记为不合适的简历。求职者可实时跟踪投递进度及时响应企业邀约。

简历编辑包含多个模块：基础信息包括头像、姓名、性别、邮箱、手机号、出生年份、所在城市、工作经验和个人介绍；求职期望包括求职类别（企业英才、兼职达人、零工快招）、职位类别、期望城市和期望月薪；教育经历包括学校名称、专业名称、学历、入学时间和其他说明；工作经历包括公司名称、担任职位、工作内容、入职时间和其他说明；个人技能由求职者自行填写；项目经历包括项目名称、项目链接、项目描述和项目开始时间；作品附件可上传WORD、PDF、PPT等格式文件。

系统提供简历开关功能：打开后简历正常展示企业可查看；关闭后企业端查看不到该简历，但已投递的企业可以正常看到。这一设计平衡求职者隐私保护与投递企业知情权，求职者可根据求职状态灵活控制简历可见性。我的积分模块展示积分余额、积分明细、我的地址和可兑换商品。求职者通过分享职位、每日签到等行为获取积分，积分可在积分商城兑换商品。我的附件支持从手机上传文件到小程序然后在作品附件中选择使用。求职端功能围绕“找工作、投简历、管进度、护隐私”四大核心场景设计。
